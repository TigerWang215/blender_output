# 光路图

光路图定义元件、料号和光束连接。平台布局记录元件在平台上的实际位置。操作见项目 [README](../README.md#从零设计光学平台)。

## 设计说明

- **实时同步。** 每次编辑光路图后，平台布局会立即更新。这个派生状态本身不产生撤销记录。撤销光路图编辑时会重新同步，恢复已删除元件原来的位置。
- **光束和连接的 ID 一致。** 光路图上的光束与平台布局中对应的光束共用 ID，测量点和历史日志可继续关联。光束消失时，测量点保留光束 ID 并归档。如果撤销等操作恢复了光束，测量点会一并恢复。
- **布局保存位置，光路图保存元件定义。** 布局记录 x、y、角度、是否自动定向和是否手动拖动（`pinned`）。其他定义来自光路图。
- **兼容旧布局。** 打开不含光路图的布局时，会按原 ID 为布局中的元件和光束分别建立元素和连接，并保留手动设置的角度和位置。

## 文件格式

`"schematic": {"elements": [...], "links": [...]}`。

- 光路图元素字段有 `kind`、`x`、`y`、`angle`、`label`、`notes`、`part`（布局元件类型，空字符串表示默认值）、`part_number`（空字符串表示默认料号）和 `auto_angle`。
- 布局元件还包含 `sch_id`、`auto_angle` 和 `pinned`。
